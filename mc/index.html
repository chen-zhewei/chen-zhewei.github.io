新手常见问题

进服需要下载什么模组吗？

不需要。这是原版 Paper 服务器，直接使用纯净客户端即可进入。如果在QQ群下载，可以直接下载我们提供的整合包。

手机可以玩吗？

完全可以。服务器支持基岩版互通，安卓用户可以在QQ群下载专门适配的手机端 Java 版启动器。

为什么强烈推荐 Radmin LAN？

Radmin LAN（蓝盾）是虚拟局域网工具，连接速度极快，延迟极低。并且走的是内网通道，不消耗服务器的公网带宽，体验最顺滑。

我的东西会被偷吗？

不会。服务器自带密码登录（AuthMe）防盗号，同时拥有强大的领地插件（Dominion），你圈的地别人进不来也拆不掉。
