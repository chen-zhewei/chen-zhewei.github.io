关于我 About Me

自 2018 年起自学编程，2021 年编写 HTML，并于 2022 年发布首个网站。从 Web 前端 到 Python 后端，从 Minecraft 服务器运维 到 硬件开发，多年来自驱探索从未间断。使用 Git 进行版本管理，在 GitHub 上持续沉淀项目与思考。

熟练掌握 Python 与 C++、Java 等语言基础，曾开发 软件、爬虫 及 检索式问答 AI。独立运维 Paper 插件服务器，热衷硬件开发，熟悉 Raspberry Pi、ESP8266 等开发板，并具备一定的 网络渗透 实践基础。持续在算法、硬件与游戏之间构建属于自己的数字世界。

Self-taught programming since 2018, started touching HTML in 2021, and released the first public website in 2022. From web front-end to Python back-end, from Minecraft server operations to hardware development, years of self-driven exploration have never stopped. I use Git for version control, continuously accumulating projects and thoughts on GitHub.

Proficient in Python with foundational knowledge of C++ and Java, with experience in software development, web scraping, and retrieval-based Q&A AI. Independently operate a Paper plugin server, passionate about hardware development, familiar with development boards such as Raspberry Pi and ESP8266, and possess practical experience in network penetration. I continue to build my own digital world across algorithms, hardware, and games.
